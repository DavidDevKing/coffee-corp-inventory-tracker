# Inventory Tracker for a Coffee Company

## A learning project for a real world scenerio

### Project Description

This project aims to simplify the tedious task of auditing valuable company assets using with web-based solution. The company in question is a made up coffee company called **Coffee Corp**. By basing this project on the needs of a company I ensure that I think of how I solve real world problems that the company may have, rather than just building a generic app for the sake of it.

**Tech Stack:** Next.js 14, Express PostgreSQL, Prisma, Docker, GitHub Actions
